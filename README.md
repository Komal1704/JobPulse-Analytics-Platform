# JobPulse — Job Market Analytics Platform

## Overview
This project analyzes salary trends, job roles, workforce insights, and remote work patterns using real-world data analytics workflows.

## Features
- ETL Pipeline
- Data Cleaning
- Data Transformation
- Exploratory Data Analysis
- Salary Analytics
- Workforce Insights

## Tech Stack
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- MySQL
